IT1811 - Laboratory Exercise 2: Reading a File
==============================================

Open StudentRegistration.sln and press F5.
FrmRegistration and FrmOpenTextFile both appear when the program starts.

FrmOpenTextFile   - Procedures 1-7 (lvShowText, btnOpen, openFileDialog1, DisplayToList,
                    exception handling + custom EmptyFileException)
FrmRegistration   - Challenge: Registration form with the new Records button.
                    Register saves to StudentRecords.txt (next to the .exe).
FrmStudentRecord  - Challenge: Register / Find / Upload buttons.

Closing FrmRegistration (the main form) ends the program.
If Visual Studio asks to retarget the framework, accept it (any 4.x works).
